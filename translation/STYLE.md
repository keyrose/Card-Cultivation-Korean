# Card Cultivation 한국어 번역 지침

## 원칙
- **원문은 중국어 간체(zh)**. 영어(en)는 참고용이며 오역·누락이 있으므로 중국어 뜻을 우선한다.
- 선협(仙俠) 장르 관례에 따라 **고유명사·수련 용어는 한자를 한국 한자음으로** 읽는다.
  - 인명: 苏怜烟 → 소련연, 冷无峰 → 냉무봉, 王氏 → 왕씨
  - 지명/문파: 雁荡城 → 안탕성, 金陵城 → 금릉성, 玄剑阁 → 현검각, 镇妖塔 → 진요탑
  - 기술/법보/공법 이름: 한자음 그대로(大衍周天经 → 대연주천경, 星辰引 → 성진인). 너무 어색하면 뜻을 살린 한국어도 가능.
  - 일반 사물(약초·재료·몬스터)은 의미가 통하는 자연스러운 한국어 우선 (兽血 → 짐승 피, 树妖 → 나무 요괴). 단, 영약·영물 이름은 한자음도 좋다(碧霄灵芝 → 벽소영지).
- 문체
  - UI·이름·버튼: 짧은 명사형 (全选 → 전체 선택, 返回 → 돌아가기)
  - 설명문·서술: `~다` 체 평서문
  - 주인공 독백(“我…”) → `나는 ~했다` 1인칭 서술
  - NPC 대사: 인물·상황에 맞게 자연스럽게(하오체/하게체/반말/존댓말). 옛스러운 무협 말투 허용.
- 중국어식 문장부호는 한국식으로: `，`→`, ` `。`→`.` `：`→`: ` `；`→`; ` `（）`→`()` `“”`→`""`/`''`  (단 `「」`, `《》`는 유지 가능)

## 반드시 보존할 것
- 태그·서식: `<br>` `<color=#xxxxxx>…</color>` `<sprite=N>` `<line-indent=20%>` `<align=center>` `</align>` `<b>` 등 **모든 `<...>` 태그를 개수·순서 그대로** 유지 (태그 안 내용은 번역 금지)
- 자리표시자: `{0}` `{1}` `{0:+0;-0;0}` `{0:P0}` 등 **그대로**
- 단축키 표기 `[K]` `[Space]` 등, 숫자, `%`
- 원문이 빈 문자열이면 빈 문자열
- 원문에 줄바꿈 문자가 없으면 넣지 말 것 (줄바꿈은 `<br>`)
